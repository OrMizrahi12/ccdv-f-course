# Lesson 0.1: How CCDV-F works and how to use this course

No code in this lesson. The hands-on happens in Claude in the browser: you attach Anthropic's official exam guide (PDF) and ask for a one-page study map, then check its numbers against the guide.

| File | What it is |
|---|---|
| `prompt-study-map.txt` | The exact prompt from the lesson (three short paragraphs). |
| `claude-sonnet-5.5-study-map.md` | The study map Claude (Sonnet 5.5) wrote in the lesson, word for word. |

The exam guide isn't copied here. Download it from Anthropic: *Claude Certified Developer – Foundations Exam Guide*, Version 1.0, linked from the CCDV-F row of Anthropic's Partner Certifications page.

Your map won't match ours word for word. Check yours against the guide: Domain 2, Applications and Integration, is 33.1%, and Claude Application Design is 8.6% (both on page 6). The item counts are estimates (weight × 53); the guide states only the weights.
