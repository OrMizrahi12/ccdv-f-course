# Claude Certified Developer – Foundations (CCDV-F): Course Materials

Companion code for the course: starter code and reference solutions for every lab, the end-state code of each lesson, and setup guides for Windows, macOS and Linux.

This is independent training material. It is not affiliated with or endorsed by Anthropic, and it contains no live exam content.

## Layout
- `setup/`: environment setup for each operating system (Python, VS Code, Node.js, git, GitHub CLI, Claude Code)
- `lessons/<id>/`: the code exactly as it stands at the end of each lesson
- `labs/L<n>/`: `starter/`, `solution/` and self-check tests for each module lab

## Before you start
1. Follow the setup guide for your operating system in `setup/`.
2. Copy `.env.example` to `.env` and put your own Anthropic API key in it. Never commit `.env`.
3. Create a virtual environment and install the pinned requirements for the lesson or lab you're working on.
